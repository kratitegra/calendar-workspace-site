プライバシーポリシー

Calendar Workspace ・ 2026年10月20日

アクセスする情報

Googleの同意画面で許可された範囲で、次の情報にアクセスします。

  • カレンダーの一覧（名前・色・アクセス権）の読み取り（calendar.calendarlist.readonly）
  • 予定の読み取り・作成・変更・削除（calendar.events）

使い道

取得した情報は、利用者自身のMacで予定を表示・編集するためだけに使います。広告、分析、AIモデルの学習には使いません。

保存場所

予定のキャッシュと操作の記録は利用者のMac内（~/Library/Application Support/Calendar Workspace）に、認証情報はmacOSのキーチェーンに保存します。開発者のサーバーはなく、Google以外の第三者へ送信・共有・販売することはありません。

削除と取り消し

アプリの接続解除で、Mac内の認証情報とキャッシュを削除できます。アクセス権はアプリ内の取り消し操作、またはGoogleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Google API サービスのユーザーデータに関するポリシー

Google APIから受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに従います。

お問い合わせ

Googleの同意画面に表示されるサポート用メールアドレスまでご連絡ください。
